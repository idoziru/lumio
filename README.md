# Lumio School Hub

Исходник устанавливаемого plugin для Codex и ChatGPT. В репозитории нет профилей семей,
школьных документов, отчётов или учётных данных.

> Перед публикацией существующего репозитория проверьте его Git-историю: в ранних коммитах могли
> остаться прежние личные данные. Для безопасной публикации создайте новый чистый репозиторий или
> отдельно согласуйте переписывание истории.

## Установка из marketplace

В ChatGPT Desktop или Codex откройте **Plugins → Marketplace → Add marketplace** и укажите
GitHub-репозиторий с этим каталогом, ветку `main` и пустое поле **Sparse paths**. Затем откройте
карточку **Lumio School Hub** и нажмите Install. Начните новый чат после установки.

## Первичная настройка

Вызовите `$lumio-school-hub настрой меня`. Скилл спросит только имя одного ребёнка и создаст
локальный профиль Lumio Private School в Пафосе в `~/.lumio-school-hub/`. Затем он коротко
объяснит простым языком, что проверяет Gmail и школьные сайты, а от родителя нужны только
подключённый Gmail, вход на школьные сайты в браузере и ссылка на новый источник, если его надо
отслеживать. Этот каталог не является частью plugin и не должен публиковаться в Git.

## Новый источник

Можно написать, например: `$lumio-school-hub добавь этот сайт как источник: <ссылка>` или
`$lumio-school-hub добавь письма с <домен>`. Скилл уточнит только недостающие сведения, проверит
доступный источник и добавит его в локальный профиль. Уже заданные источники Lumio не изменяются.

## Обновление plugin

Измените `plugins/lumio-school-hub/`, увеличьте `version` в `.codex-plugin/plugin.json`,
закоммитьте и отправьте изменения в ветку `main`. Пользователь открывает ту же карточку
marketplace, обновляет или переустанавливает plugin и начинает новый чат.
