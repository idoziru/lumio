# Lumio School Hub

Lumio School Hub помогает родителю проверять школьную почту, сайты, документы и календарь.
Профиль семьи, документы и отчёты хранятся только на устройстве пользователя.

## Установка из marketplace

В ChatGPT Desktop или Codex откройте **Plugins → Marketplace → Add marketplace**. В поле
**Source** укажите `idoziru/lumio`, в следующем поле — `main`, а **Sparse paths** оставьте пустым.
Затем откройте карточку **Lumio School Hub**, нажмите Install и начните новый чат.

## Первичная настройка

Вызовите `$lumio-school-hub настрой меня`. Скилл попросит имя ребёнка и класс латиницей,
например: `Petr Petrov, 1D`, — и создаст локальный профиль Lumio Private School в Пафосе в
`~/.lumio-school-hub/`. Затем он сам проверит Gmail, браузер и школьные сайты. В результате
понятно напишет, что уже работает, где нужно войти и что именно сделать. Пароли не нужны.

## Новый источник

Можно написать, например: `$lumio-school-hub добавь этот сайт как источник: <ссылка>` или
`$lumio-school-hub добавь письма с <домен>`. Скилл уточнит только недостающие сведения, проверит
доступный источник и добавит его в локальный профиль. Уже заданные источники Lumio не изменяются.

## Обновление

Откройте **Plugins → Marketplace**, выберите marketplace Lumio School Hub и нажмите **Sync now**.
Если у самой карточки плагина есть кнопка **Refresh**, используйте её. После синхронизации начните
новый чат. Кнопка **Update** может не показываться — это нормально. Локальный профиль семьи при
этом не удаляется.
