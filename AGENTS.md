# Lumio School Hub

Распространяемый plugin для школьного хаба: он собирает и систематизирует новости, документы, даты и сведения о ребёнке только из официальных школьных источников.

- Общайся и веди файлы на русском; названия разделов, событий, предметов и имена сотрудников сохраняй в оригинале для поиска.
- Не выдумывай факты: непроверенное явно помечай. Для каждого факта в `NEWS.md` и `CALENDAR.md` обязателен источник.
- Персональные данные используй только для задач этого проекта. Не записывай и не раскрывай пароли, коды 2FA, токены и другие секреты.
- Не отправляй письма, ответы, формы и заявки от имени родителя без его явной просьбы.
- Для школьных задач обязательно используй скилл `$lumio-school-hub` из `plugins/lumio-school-hub/`.
